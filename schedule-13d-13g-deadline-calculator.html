How To Use The Date Without Overclaiming

1. Start With Filer Category

Confirm whether the person is a Schedule 13D filer, QII, exempt investor, passive investor, or no filer before treating any date as operative.

2. Separate Date Types

Some scenarios run from an acquisition or material-change date; others run from month end or quarter end. The calculator labels the base date used.

3. Check The SEC Calendar

The worksheet includes standard U.S. federal holidays and skips weekends. Add emergency SEC closure dates or special non-filing dates manually.

4. Treat Output As A Checklist

Use the memo and CSV row to queue source review, EDGAR preparation, signatures, exhibit checks, and counsel review before any filing decision.
